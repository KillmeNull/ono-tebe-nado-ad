# Оно тебе надо

Учебный проект Яндекс Практикума — страница аукциона вещей, в которые никто не верил.

Страница свёрстана по макету Figma с использованием HTML и CSS. Для расположения элементов используются Flexbox и Grid.

Чтобы посмотреть проект, откройте файл `index.html` в браузере.

[Репозиторий проекта](https://github.com/KillmeNull/ono-tebe-nado-ad)
